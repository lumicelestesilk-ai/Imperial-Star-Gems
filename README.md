# Imperial Star Gems

White-luxury Next.js storefront for loose natural and lab-grown diamonds.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — home and rough-to-polished hero sequence
- `/natural-diamonds` — natural diamond catalogue
- `/lab-grown-diamonds` — lab-grown diamond catalogue
- `/shapes` — shape gallery
- `/craftsmanship` — process and certification overview
- `/contact` — enquiry form and direct contact paths

The catalogue intentionally contains no pricing. Every stone routes visitors to an enquiry.
